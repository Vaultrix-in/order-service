# 📦 Vaultrix Order Service

Handles the lifecycle of orders, transactions, and service fulfillment.

## ⚙️ Logic
- Order creation and status tracking.
- Integration with the Wallet service for payment verification.
- Event triggering for Invoice and Notification services.
